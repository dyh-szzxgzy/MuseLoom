# Sample Assets

This folder stores roadshow-friendly example assets for the MuseLoom demo.

## Current Files

- `sample_audio.wav`: original classroom input placeholder
- `generated_demo.wav`: regenerated music placeholder
- `sample_analysis.json`: structured analysis example
- `sample_visual_prompt.txt`: multimodal appreciation prompt sample
- `sample_teacher_notes.md`: suggested classroom explanation notes

## Replacement Suggestion

For final presentation, replace placeholder wav files with short real clips between 10 and 30 seconds.
