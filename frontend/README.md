# Frontend Module

This frontend is a presentation-oriented interface for the MuseLoom project.

## Current Capabilities

- Display analysis tags for uploaded or sample audio
- Show a canvas-based spectrum view
- Allow prompt editing for style transfer demos
- Prefer backend API calls and fall back to local mock data

## Demo Entry

Open `index.html` directly for static preview.

If the backend is running on `http://localhost:8080`, the page will call `/api/demo-flow`.
