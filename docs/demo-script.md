# Demo Script

## Goal

Show the audience how MuseLoom helps students move from listening to creating and then to appreciation.

## Script Outline

1. Upload a short music clip.
2. Explain the extracted mood, tempo, and style tags.
3. Edit one or two prompt descriptors in the interface.
4. Trigger music regeneration and compare before and after.
5. Display the visual prompt result as a multimodal appreciation aid.

## Notes

- Prefer one short sample audio file for live demos.
- Keep each generation example focused on one clear style change.
- Use notebook screenshots if live model inference is unavailable.
