# CLAP Analysis Module

This folder contains placeholder scripts and notebooks for audio understanding in the MuseLoom pipeline.

## Intended Responsibilities

- Extract rhythm and spectral features from uploaded audio.
- Map features into interpretable mood and style tags.
- Produce teaching-oriented descriptors for the frontend.

## Current State

- `extract_features.py` contains a demo feature extraction stub.
- `emotion_mapper.py` contains a simple tag mapping placeholder.
- `notebooks/clap_audio_analysis_demo.ipynb` is a presentation notebook scaffold.
