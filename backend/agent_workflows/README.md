# Agent Workflows

This folder stores placeholder workflow definitions for Dify and Coze style orchestration.

## Intended Flow

1. Analyze uploaded audio and derive style and mood tags
2. Revise prompt text into a generation-oriented recipe
3. Generate a transformed music clip with MuseLoom
4. Produce a visual appreciation prompt for classroom comparison

## Current State

- Definitions are illustrative and aligned with the backend mock services.
- They are suitable for roadshow explanation and later tool export.
- `demo_run_example.json` shows a sample execution trace for presentation use.
- `workflow_explanation.md` explains why the orchestration is structured this way.
